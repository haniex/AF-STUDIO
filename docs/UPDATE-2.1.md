## Экран входа — «AURUM»
Модуль `js/three/aurum.js` — развитие первого фона AF: скульптура-узел из жидкого чёрного хрома, которая медленно течёт
(деформация на видеокарте), с переливающимся золотисто-голубым краем; студийные полосы света в отражениях;
три золотые орбиты с бегущими «кометами» света; 7 парящих хромированных, золотых и лаковых объектов; лучи света за
скульптурой; шёлковые золотые нити дыма на фоне; золотая пыль с эффектом боке, которая расступается вокруг курсора.
Постобработка: свечение (bloom), кинематографическая цветокоррекция ACES, лёгкая хроматическая аберрация, виньетка, зерно.
Клик по фону — волна проходит по металлу; вход — «прыжок» камеры сквозь узел со вспышкой.
Карточка входа — стекло с анимированной золотой обводкой; автозаполнение Chrome больше не красит поля.
Качество — Настройки → Эффекты и 3D («Экономное» отключает постобработку).
Файлы: `js/three/aurum.js` (новый), `js/auth/access.js`, `css/platform-v2.css`. Файл `js/three/space.js` удалён.

## 1. Обновить сайт на GitHub
Замените/добавьте в репозитории `AF-STUDIO` файлы из архива (проще всего — загрузить всю папку поверх, GitHub заменит изменённые):
`index.html`, `admin.html`, `css/platform-v2.css`, всю папку `js/` (новые: `js/three/`, `js/core/fx.js`, `js/core/prefs.js`).

## 2. SQL (1 файл)
SQL Editor → вставить `supabase/migrations/20261125000006_owner_notifications.sql` → Run. Проверка вернёт строку `trg_profile_new_user`.

## 3. Как заходить в админку
- Адрес: **https://haniex.github.io/AF-STUDIO/admin.html** (сохраните в закладки).
- Или в платформе: пункт **AF Admin** внизу левого меню, в меню аватара (справа вверх), плашка на главной, кнопка в Настройках.
- Видно только аккаунтам с ролью admin (`make-admin.sql`). Остальным — «Доступ запрещён».

## 4. Telegram-уведомления (проверено, работает)
1. **@BotFather** → `/newbot` → получить токен. Открыть своего бота и нажать **Start**.
2. **@userinfobot** → написать ему от себя (не пересылать!) → ваш личный id.
   Не используйте число из начала токена — это id бота, Telegram ответит «bot can't send messages to the bot».
3. Edge Functions → Secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (ваш личный id), `SITE_URL`.
4. Edge Functions → функция `notify` → код из `supabase/dashboard/notify.ts` → Deploy → **Verify JWT выключен**.
5. SQL Editor → `supabase/migrations/20261125000008_notify_auto.sql` целиком, без изменений.
   Раздел «Database → Webhooks» не нужен: отправку делает триггер в базе, секрет создаётся автоматически.
6. Роль администратора — `supabase/make-admin.sql` (с вашим email входа). Telegram получают только админы.
Проверка: `supabase/test-notify.sql`, диагностика: `supabase/check-notify.sql` (колонка `response` показывает причину).

## 5. Email-уведомления клиентам (по желанию)
1. [resend.com](https://resend.com) → регистрация → **Domains** → добавить свой домен и DNS-записи (без своего домена письма можно слать только себе).
2. **API Keys** → создать ключ.
3. Secrets: `RESEND_API_KEY` = ключ, `MAIL_FROM` = `AF Studio <studio@ваш-домен>`.
Используется тот же триггер из шага 4 — ничего больше настраивать не нужно.

## 6. Вход через Google (≈10 минут)
1. [console.cloud.google.com](https://console.cloud.google.com) → создать проект `AF STUDIO`.
2. **APIs & Services → OAuth consent screen** → External → название `AF STUDIO`, ваш email → Save. Затем **Publish app**.
3. **Credentials → Create credentials → OAuth client ID → Web application**:
   - Authorized JavaScript origins: `https://haniex.github.io`
   - Authorized redirect URIs: `https://iotgzyfqvsuefpqyhvrn.supabase.co/auth/v1/callback`
4. Скопируйте **Client ID** и **Client secret** → Supabase → **Authentication → Sign In / Providers → Google** → Enable → вставить → Save.
5. Обновите страницу входа — кнопка Google появится сама.

## 7. «До / После»
Раздел намеренно пуст: по требованиям проекта там допускаются только **реальные** материалы (исходник/фото, черновой clay-рендер, финал). Сгенерированные «черновики» выдавали бы фейк за процесс работы.
Добавить: AF Admin → **До / После** → «Добавить» → загрузить 2–3 изображения (из рабочих файлов проекта) → сохранить. Ползунок появится у клиентов сразу.
