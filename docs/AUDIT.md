## Технические проблемы, найденные при аудите
1. **Весь контент публичен** — тексты и данные проектов лежат в HTML/JS (решено: перенесены в БД с RLS для авторизованных).
2. **Aether Guardian** использует стоковое фото Unsplash, а не реальный рендер (оставлено как есть, помечено в сиде — заменить в AF Admin).
3. `body { cursor: none }` глобально — ломает UX форм (переопределено в платформе).
4. `section, .container { overflow: hidden }` — обрезает поповеры (компоненты платформы не используют эти обёртки).
5. Отзывы захардкожены (3 шт.) — перенесены в таблицу `reviews` без изменений; **владельцу нужно подтвердить, что они реальные**.
6. Цены в FAQ указаны текстом — перенесены в редактируемые таблицы `pricing_*`.
7. Мёртвый код: `initTestimonials` (элементов `.testimonial` нет), `.process-step` в GSAP (элементов нет).
8. Formspree-эндпоинт виден в коде (нестрашно, но спам-защиты кроме `_gotcha` нет).
9. Нет CSP, нет `noindex` для закрытых страниц (добавлено).

## Возможные конфликты при внедрении и решения
| Риск | Решение |
|---|---|
| Глобальные стили `styles.css` (`.header`, `.btn`, `section`) | Платформа использует собственный префикс `af-` / `acc-`; классы оригинала применяются только там, где переиспользуются осознанно |
| GitHub Pages не исполняет серверный код | Вся серверная логика — Supabase (RLS, SQL-функции, Edge Functions); фронтенд статический |
| SPA-маршруты на статическом хостинге | Hash-роутинг + `404.html`, который отправляет любой путь (`/studio`, `/projects`…) через guard |
| Two scripts управляли одним DOM | Каждый вид рендерится в собственный контейнер и возвращает cleanup (рендереры Three.js, realtime-подписки освобождаются) |
