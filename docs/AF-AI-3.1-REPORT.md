# AF AI 3.1 — Universal Creative Assistant + исправления входа

> Честно о проверках: unit-тесты (30/30) и синтаксис пройдены здесь. Реальные вызовы Gemini,
> SQL-миграция и вход по ссылке из письма **здесь не запускались** — нет доступа к вашему Supabase
> и браузеру. Что проверить после публикации — §9.

## 1. Что изменилось для пользователя

**Настройки.** Пункт «Настройки» убран из бокового меню. Настройки открываются только из меню аккаунта
(снизу слева или по аватару) и сочетанием `Ctrl + ,`. Ссылка `#/settings` продолжает работать.
Стили старой страницы настроек удалены.

**Восстановление пароля.** Раньше ссылка из письма работала только в том же браузере, где запросили сброс
(PKCE), и дольше не жила. Если её открыть в почтовом приложении или в другом браузере, а также если
почтовый сканер «нажимал» её первым, вход заканчивался тем же экраном входа. Теперь:
- после «Отправить ссылку» открывается экран **«Сброс пароля по коду»**: email + код из письма + новый пароль — работает на любом устройстве;
- новый шаблон письма содержит ссылку с `token_hash` — она открывается в **любом** браузере и сразу ведёт на экран «Новый пароль»;
- если ссылка всё-таки не сработала, показывается экран ввода кода с понятным объяснением, а не экран входа.

**Лимит попыток входа.** В коде сайта ограничения попыток нет и не было. Ошибка «Слишком много попыток»
приходит от сервера Supabase Auth (защита от подбора паролей). Полностью отключить её из кода нельзя —
её можно поднять в панели (§8, шаг 4). Текст ошибки стал понятнее.

## 2. AF AI 3.1 — что умеет

AF AI = общий помощник + специализация AF STUDIO. Один чат, одна история, одна система лимитов, один Gemini.

| Контекст | Что делает |
|---|---|
| **Общий** (по умолчанию для новых чатов) | Любые обычные задачи: вопросы, тексты, переводы, учёба, код, документы, бизнес-идеи, дизайн, анализ. База знаний AF **не загружается** — системная инструкция ~2,7 тыс. символов вместо прежних тысяч токенов |
| **AF STUDIO** | Услуги, цены, портфолио и база знаний студии. Цены, сроки, клиенты, условия не выдумываются. Остаётся «Подключить администратора» |

ТЗ, смета, подсказки конструктора и анализ мудборда всегда работают в контексте AF STUDIO.
Переключатель «Общий / AF STUDIO» есть вверху чата и в поле ввода. Для сохранённого диалога выбор
записывается в базу только после нажатия пользователя.

### Режимы
`chat` · **`create`** (новый) · `brief` · `estimate` · `builder_hint` · `moodboard` — старые режимы не удалены.

### Типы результата в `create` (проверяются на сервере, `output_type`)
`text`, `social_post`, `video_script`, `email`, `document`, `plan`, `table`, `code`, `html_component`, `image_prompt`, `other`.
Неизвестное значение → `400 bad_output_type`. У каждого типа своя короткая инструкция формата.

### Системные инструкции — разделены
Base · General · AF Studio · Create (+ формат типа) · Brief · Estimate · Builder hint · Moodboard · Safety.
Каждый запрос получает только нужные блоки. Убраны «Use ONLY the knowledge base» и «предлагай администратора»
для общих тем. Блок безопасности идёт последним и сильнее заметок владельца (`extra_instructions`).
В общем контексте заметки владельца применяются только к вопросам об AF STUDIO.
Модель предупреждена: нет доступа к интернету, нельзя утверждать, что код запускался, что изображения
сгенерированы или что выполнены внешние действия.

### Размер ответа (только на сервере)
chat: 800 / 1800 / 2600 токенов (кратко / сбалансированно / подробно), create: 3500 (кратко — 2400),
ТЗ/смета: 2200, жёсткий потолок 4096. Для слишком больших задач модель начинает с фразы
«Это большая задача. Давай разделим её на несколько частей…» и выдаёт первую рабочую часть.
Если ответ оборван лимитом, сервер возвращает `truncated`, а интерфейс предлагает «Продолжить».

## 3. Интерфейс AF AI (новый, спокойный)

- Слева — новый диалог, поиск, группы «Сегодня / Вчера / 7 дней / 30 дней / Ранее», меню «⋯» у каждого диалога (переименовать, перевести в другой контекст, удалить).
- Верх — «AF AI», переключатель контекста, компактная квота (нажатие открывает подробную статистику), меню «⋯» (передать администратору, настройки AF AI, удалить).
- Пустой экран — «Чем займёмся?» и максимум три примера.
- Поле ввода — `+` (меню «Создать» с 11 типами и режимы ТЗ/смета), плашка выбранного режима, переключатель контекста, кнопка отправки.
- Палитра строго по ТЗ: #0E0E0D / #171614 / #34312B / #ECE9E3 / #A8A198 / акцент #C6A078; светлая тема — свои значения. Никаких сфер, орбит, свечения и декоративных карточек.
- Мобильная версия: история выезжает панелью, кнопки действий иконками, поле ввода 16 px (без зума на iOS).

## 4. Экспорт результатов

| Действие | Как работает |
|---|---|
| Копировать | весь ответ |
| Сохранить | как раньше (`ai_messages.saved`) |
| Скачать | `.md` (как есть) или `.txt` (очищенный от разметки) |
| Повторить | последний ответ; на сервере старая пара заменяется только после успешного нового ответа |
| Улучшить | подставляет «Улучши предыдущий результат: …» |
| Продолжить | у последнего ответа |
| В конструктор | в контексте AF STUDIO |
| Блок кода | язык, «Копировать», «Скачать .ext» |

Расширения — только из allowlist `.html .css .js .ts .py .sql .json .md .txt`, остальное → `.txt`.
Имя файла очищается (`af-ai-<тема>-<дата>.<ext>`). Файлы скачиваются как `text/plain`.
Код **не исполняется**: нет `eval`/`Function`, вывод модели не вставляется как HTML — всё экранируется,
подсветка синтаксиса — собственный безопасный токенизатор. DOCX/PDF не имитируются; точка расширения —
`js/core/ai-render.js` (`downloadText` / будущий экспортёр).

## 5. Изображения
Генерации изображений **нет** и она не показывается как функция. Тип `image_prompt` создаёт промпты и явно
говорит, что это промпты. Для будущего провайдера предусмотрена отдельная Edge Function (свой секрет, JWT,
лимиты, приватный Storage) — в этом обновлении не реализована.

`20261126000003_ai_scope.sql`: колонка `ai_conversations.scope` (`general | af_studio`, CHECK).
Существующие диалоги → `af_studio` (поведение не меняется), новые → `general`. Владелец может менять только `title` и `scope`

## 8. Что сделать в Supabase (вручную)

1. **SQL Editor** (автоперевод выключить) → `supabase/migrations/20261126000003_ai_scope.sql` → все флаги `true`.
2. **Edge Functions → ai-chat → Code** → вставить весь `supabase/dashboard/ai-chat.ts` → **Deploy** (Verify JWT — OFF). Изменение локального файла само по себе опубликованную функцию **не меняет**.
3. **Authentication → Emails → Reset Password** → Subject «AF STUDIO — сброс пароля», тело — весь `supabase/email-templates/reset-password.html`. По желанию так же **Confirm signup** ← `confirm-signup.html`.
   **Authentication → URL Configuration → Site URL** = `https://haniex.github.io/AF-STUDIO`.
4. **Authentication → Rate Limits** — поднять лимиты входа и проверки кодов (например, sign-ins/sign-ups 100+ за 5 мин на IP, token verifications 100+).
   Важно: со встроенной почтой Supabase отправляет **2–3 письма в час на весь проект** — из-за этого письма сброса часто не приходят.
   Для нормальной работы подключите SMTP (Resend / Яндекс 360) в **Authentication → SMTP Settings**, тогда лимит писем можно поднять.
5. Загрузить содержимое `AF-STUDIO/` в репозиторий → Ctrl+Shift+R.

Новые секреты не нужны.

## 9. Тесты

**Пройдено здесь:** 30/30 unit-тестов (24 прежних + 6 новых):
безопасный рендер (XSS в коде и тексте), подсветка JS/SQL, оборванный блок кода, таблицы и цитаты, allowlist расширений,
безопасные имена файлов, экспорт в TXT, группировка истории по датам, поиск, эффективный контекст, контракт сервера
(совпадение типов результата клиента и сервера, старые режимы на месте, общий prompt не ограничен базой AF, база AF
грузится только в контексте AF, минутный лимит для всех режимов до дневного, бюджет 3500 для create, синхронность dashboard-версии),
восстановление по token_hash/коду, «Настройки» убраны из меню.
Дополнительно: сборка системных инструкций проверена вызовом `buildSystem()` (общий контекст без базы AF ~2,7 тыс. символов,
AF-контекст с базой, заметки владельца ограничены, блок безопасности последний); бюджеты токенов 3500/2400/1800/2600/700.
Синтаксис 57 JS-модулей и функции ai-chat; все импорты разрешаются.
У вас: `node --test tests/unit.test.mjs`.

**Проверить после публикации (не выполнялось здесь):**
- Общий контекст: вопрос не про AF, текст, перевод, сценарий TikTok, название, учебная тема, HTML/CSS-блок, SQL, таблица, документ.
- AF STUDIO: цена услуги, существующий проект, ТЗ, смета, отказ выдумывать неизвестную цену, передача администратору.
- Старый диалог открывается в контексте AF STUDIO, новый — «Общий»; переключение сохраняется после перезагрузки.
- Квота уменьшается после каждого режима; при ошибке Gemini запрос не списывается.
- Сброс пароля: запросить на телефоне → открыть ссылку на компьютере → экран «Новый пароль»; ввод кода из письма.

## 10. Ограничения
Нет доступа к интернету, запуска кода, генерации изображений, экспорта DOCX/PDF — и AF AI об этом не заявляет.
Поиск — по названиям диалогов (последние 100). Подсветка синтаксиса упрощённая (ключевые слова, строки, комментарии, числа, теги).
