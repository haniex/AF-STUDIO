## Ручной чек-лист (перед публикацией)
### Авторизация
- [ ] Открыть сайт в приватном окне → виден только экран загрузки AF, затем AF Access
- [ ] Прямые ссылки без входа: `#/projects`, `#/studio`, `#portfolio`, `/AF-STUDIO/studio`, `/AF-STUDIO/projects`, `project.html?id=haniex`, `admin.html` → везде AF Access
- [ ] Регистрация: ошибки валидации (email, пароль < 8, несовпадение, без согласия), повторный клик не создаёт дубль
- [ ] Письмо подтверждения → ссылка → «Email подтверждён» → вход
- [ ] Регистрация на существующий email → понятное сообщение
- [ ] Вход с неверным паролем → «Неверный email или пароль» (без технического текста)
- [ ] «Запомнить меня» выкл. → закрыть вкладку → снова вход; вкл. → сессия сохраняется после перезапуска браузера
- [ ] Обновление страницы внутри платформы → остаётесь в том же разделе без повторного входа
- [ ] Забыли пароль → письмо → новая вкладка → форма «Новый пароль» → вход
- [ ] Выход → AF Access; кнопка «Назад» браузера не показывает данные
- [ ] Удалить `af-studio-auth` руками / подставить мусор в localStorage → после перезагрузки AF Access

### Права доступа (два тестовых клиента A и B + админ)
- [ ] A не видит проекты, файлы, сообщения, мудборды, AI-чаты B (в т.ч. по прямому UUID в адресе)
- [ ] A не может через консоль: `supabase.from('projects').update({status:'done'})`, `insert` в `user_roles`, `update profiles set email`, вставку `files` с `kind:'final'`
- [ ] A не может удалить итоговый файл, загруженный админом
- [ ] Не-админ на `admin.html` → «Доступ запрещён»; RPC `admin_stats` → ошибка forbidden
- [ ] Anon key без входа: любые `select` → пусто/ошибка
